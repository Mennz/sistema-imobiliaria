# Sistema de Gestão Imobiliária

Projeto de modelação e desenvolvimento de um sistema imobiliário, construído para a disciplina de Programação Orientada a Objetos.

## Descrição do Projeto
O sistema tem como objetivo gerir imóveis, clientes, corretores, visitas e propostas de aluguel e venda. O foco principal da arquitetura é a aplicação prática e estruturada dos quatro pilares da Orientação a Objetos (Abstração, Encapsulamento, Herança e Polimorfismo).
